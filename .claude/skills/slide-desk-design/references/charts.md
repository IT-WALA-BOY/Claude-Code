# Charts

Three shapes cover the monthly deck. All settled treatments below are fixed — they are not options to offer the user.

| Shape | Used for |
| --- | --- |
| Combo | Bars on one axis, a line on a second — volumes against a rate |
| Stacked column | Part-to-whole across categories |
| Simple column | One series compared across options |

## Settled treatments

**Palette.** Non-subject bars `#9FC0F5`, secondary series `#DBE8FF`, line series `#0E3A70`, subject `#1767FF`. One hue carries the structure; the brand colour marks the subject — the same rule the tables follow. This keeps Accent/Yellow free to mean a promotional tag rather than a data series.

**Highlight.** On. Neutral bars with the subject in saturated brand blue, and its data label a step larger in the same colour.

**Data labels.** All — but "all" is defined per shape rather than meaning every mark:

- Combo: every bar, but not the line's points. The right-hand axis carries those; 26 labels on one chart is unreadable.
- Stacked column: the stack total above the column, not the individual segments.
- Simple column: every bar.

Past roughly twenty categories, fall back to subject-only rather than shrinking the type. A 7px label is not a label.

**Gridlines.** Five horizontal in `#EDEFF2`, baseline `#C9D0D8`, axis values `#9AA1AA` at 8.4px weight 600. Bar labels 9px 700 `#555`; the subject's label 11.5px 800 brand blue. Key text 9px 600 `#6B7178`. **No vertical gridlines on any chart type.** A chart is read by comparing heights, so vertical lines add structure nobody needs and compete with the bars. This mirrors the full-grid table rule rather than contradicting it — a projected table is read at rest and every cell is a value to find.

**Key.** Swatches, always shown, below the chart, sharing that line with the caption — key left, caption right, both aligned to the plot. Inside the plot is available and lands in the emptiest corner, computed per chart from where the data sits. A boxed key is for when the key sits over content, as on a map; over an empty corner it is unnecessary weight.

## Second axis

Label it. A reader cannot tell that a line is a percentage and the bars are counts without reading the series names. Name it in the key too — "Churn % (right axis)".

## Layout

Two charts side by side is the standard layout, each with its own caption. Every chart's title, plot, gridlines, axis, key and caption share the same left and right bounds.

## Screenshots are out

A pasted dashboard panel carries another product's visual language onto the slide and can follow none of the above. Rebuild the chart. This is the single biggest visual inconsistency in the historical decks.
