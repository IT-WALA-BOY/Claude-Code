# Workflow Dashboard

A private, single-admin dashboard for tracking tasks, expenses, goals, LinkedIn outreach, Figma work, and income.
Plain PHP + MySQL, deployable via XAMPP export to Hostinger (can sit next to a WordPress site in a subfolder).

See [docs/plan.md](docs/plan.md) for the full plan and roadmap.
